# Requirements

## Core Gameplay
- [ ] 장르: 2D 로그라이크 액션 게임
- [ ] 타겟 플랫폼: PC (키보드 및 마우스 조작)
- [ ] WASD 키를 이용한 8방향 캐릭터 이동
- [ ] 마우스 커서 방향으로의 대시 기능
- [ ] 마우스 좌클릭을 통한 근접 검 공격
- [ ] 마우스 우클릭을 통한 원거리 투척 무기 공격

## UI
- [ ] 메인 메뉴 화면 (게임 시작 및 종료 등)
- [ ] 인게임 HUD (플레이어 체력 및 획득 골드 표시)
- [ ] 게임오버 화면 (재시도 및 메인 메뉴 이동)

## Out of Scope
- [ ] 멀티플레이어 기능 (싱글플레이 전용)
